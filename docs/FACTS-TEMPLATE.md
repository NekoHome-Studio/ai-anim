# FACTS.md 模板 —— 对外材料的事实出处

> **什么时候要写这份**：片子代表**某个团队 / 某个项目**对外发声时（介绍片、宣传片、发布视频）。
> 这时候每一句文案都是一次"代表他们说话"，写错了比画面难看严重得多。
>
> 做法只有一条：**宁可留空，也不许编造或推测**。写不出出处的句子，就不要放进片子。
>
> 这份模板已经被连续两支片子用过（`tasks/nekohome/FACTS.md`、`tasks/fidus/FACTS.md`），
> 它是刚需而不是仪式：上一次它直接逼出了「用户给的矩阵表和仓库 `docs/spec.md` §2.1 对不上」
> 这个**必须发问才能定**的问题（`docs/history/IMPROVEMENTS-1-3.md` §4）。
>
> 用法：`cp docs/FACTS-TEMPLATE.md tasks/<任务>/FACTS.md` 然后逐节填。

## ★ 数字的硬规则（先读这一节，再往下填表）

> 这一节是 `docs/BACKLOG.md` **1-22** 的纪律那一半（另一半是工具：
> `node tools/lint-fabricated-numbers.mjs <任务>`）。它的原话：
> **「这条对我们的伤害面最大 —— 我们的画面全是代码算的，编一个数字的成本是零。」**

**五条，缺一条这份事实表就白写：**

1. **绝不在帧尺度上编造数字、增量、日期、计数。**
   画面上的每一个数字 —— 包括"示意动画"里那个每秒都在跳的计数器 ——
   要么能在**这一份 FACTS.md 的正文里找到**，要么写成占位符。

2. **槽位先渲染成 `— figure —`。**
   读数还没拿到、作者还没确认、上游数据还没采——**先把槽位画出来**（一个短横、两个字、
   版面占位），别先填一个"看起来合理"的数。`— figure —` 是这个仓库的既定写法
   （出处在 `REFERENCE-hyperframes.md` §4.3 的 Pre-Render Self-Audit）。
   理由很实际：**一个编出来的数比一个空槽位危险得多** —— 空槽位会被看见、被追问；
   编出来的数会一路进成片，而且没人会发现。

3. **"示意"也要登记，而且要写清它不等于真实数据。**
   示意动画（计数器、延迟条、进度条）**不需要**有外部出处，但**必须**在 §3 那张表里
   点名"这是示意"，并说明它代表什么、不代表什么。`tasks/nekohome/FACTS.md` 的写法可以直接抄：
   > 「NekoClicker 那个计数器读数、每秒增量、柱状条：都是按时间算出来的示意动画，
   >   不是仓库里的真实数值。」

4. **片子自己的编号也要登记。**
   `WORKS 04`、`取证 02 / 42 份协议 XML`、`v0.1.2`、`共十一个`、`L9 / L0` 这类
   "是我们自己排的号"的数字，同样要进 §1 或 §5 —— 它们不是外部事实，但**它们是画面上出现的数字**，
   登记一行（写"本片镜号"）比事后被人问"这个 04 是哪来的"便宜得多。
   ⚠ 这一条是工具第一次跑真任务时**当场**提出来的：`node tools/lint-fabricated-numbers.mjs nekohome`
   报了 4 个值，全是 `kicker: 'WORKS 0x / …'`（见 §5 的表格）。

5. **算出来的数字要登记口径。**
   `String(cnt).padStart(2, '0')`、`${(v * 100).toFixed(1)}%`、`'防线 ' + (i + 1)` 这类数字**不是字面量**，
   静态判据看不见它等于几 —— 工具会把它单列成一段：
   `算出来的值：N 处 —— 这些位置静态查不到等于几，这一项**没验**`。
   两条路**二选一**：**① 在 §1 / §3（或这一节）写明它的口径** —— 这个数是怎么来的、代表什么、
   不代表什么（「按时间算的示意动画」「读数从 0 数到 42」都算登记）；**② 渲染成占位符 `— figure —`**。
   ⚠ 什么都不写就等于「这一处没人验过」—— 而那正是「编一个数字」**最隐蔽**的形式：
   它连字面量都不是，报告里却曾经读起来像「全都查过了」（`docs/BACKLOG.md` 第九轮待办 ③）。
   工具会逐条给出 `文件:行号` 与那一行原文，照着改就行；**它不改退出码** ——
   所以「退出码 0」**不等于**「算出来的那些都验过了」，那一段必须人眼过一遍。

**交付前自审（三条命令，逐条对号）**：

```sh
node tools/lint-fabricated-numbers.mjs <任务>          # 画面上的数字有没有出处（零命中才算过）
node tools/lint-fabricated-numbers.mjs <任务> --slots  # 它到底把哪些位置当成"数值显示位"（判据复核）
node tools/lint-fabricated-numbers.mjs <任务> --explain # 连找到出处的也打出来，附 FACTS.md 行号
```

⚠ 第一条命令的输出里还有一段 **`算出来的值：N 处 —— 这些位置静态查不到等于几，这一项**没验**`**
（判据 ③）：那几处**不进退出码**，所以「零命中」**不等于**它们验过了 —— 逐条看，按上面第 5 条处理。
0 处也会打一行（`算出来的值：0 处`）：没有那一行就说明这一段没执行，不是「这一类不存在」。

工具**只扫"数值显示位"**（会真的画到帧上的字符串里的数字字面量）：文字入口
（`type.write` / `writeLine` / `put` / `codeRow` / `caption` / `kicker` / `footer`）的文本、
任务自己包装了一层再画的函数的实参、镜头模板与配置档节点的参数（`values` / `title` / `sub` /
`footer` / `label` / `unit`）、旁白与字幕文本，以及**流向**这些位置的变量与数组元素。
**不算**：坐标 / 字号 / 时长 / 阈值 / 颜色分量 / 枚举字符串 / 注释。
⚠ **算出来的数**（模板串插值 / 字符串拼接 / `String()` / `.padStart()` / `.toFixed()`）不进「有出处」
那一档 —— 它们被单列成「算出来的值：N 处 …… 这一项**没验**」，按上面第 5 条处理。

⚠ **没有 `FACTS.md` 的任务会被工具安静跳过**，并且明确打一行「没有事实表 ⇒ 这一项没验」。
那是**没验**，不是**通过**（`docs/DIAGNOSIS.md` §3「空 ≠ 干净」）。

## 2. 刻意没写的东西及原因（**这一节和 §1 一样重要**）

没写的东西往往比写了的东西更能说明这份材料是否可信。逐条写：为什么不写。

| 没写的内容 | 为什么 |
|---|---|
| （例）性能数字 | 官方文档没有给出可复现的 benchmark，写任何数字都是编 |
| （例）"由 X 团队开发" | 仓库公开文档里没有出现该团队名 —— 署名口径需要作者确认，不能自行推定 |
| （例）路线图里的未发布功能 | 属于规划而非事实，写进"现在时"的介绍片会误导 |
| | |

## 3. 画面里哪些是示意（不是数据）

介绍片常用"示意动画"表达抽象概念 —— 这没问题，但**必须自己标注清楚**，
否则观众会把示意图当实测图。

⚠ **示意不等于免登记**：示意读数（计数器、延迟条、进度条）与**片子自己的编号**
（`WORKS 04` / `取证 02` / `L9`）也要在这张表里有一行 —— 工具会把它们算成"数值显示位"，
而它的判据只有一条：**这个数字串能不能在 FACTS.md 的正文里找到**。
找不到就报 `file:line`，那时你只有两条路：补一行到这里，或者把那个数去掉。两条都对。

| 镜头 | 画面内容 | 性质 | 说明 |
|---|---|---|---|
| （例）镜头 05 | 坐标轴与网格动画 | 示意 | 用于表达"解算"这一动作，不是任何一次实测的截图 |
| （例）镜头 07 | 延迟条长度 | 示意 | 长度与真实延迟无对应关系 |
| （例）镜头 04 | 眉标 `WORKS 04` | 本片镜号 | 编导编号，不对应作品编号 / 版本号 / 任何外部事实 |
| （例）镜头 02 | 读数槽位 `— figure —` | 占位符 | 真实读数还没采到，先占位（**交付前必须替换或删掉这一行**） |
| | | | |

## 5. 引用格式（片上/文案里怎么标）

- 引用原文时用引号，且**不加修饰词**（"业界领先""革命性"这类词一律不要，除非原文就有）。
- 数字必须带限定条件（哪台机器、哪个版本、什么环境）。「42 份协议 XML」这种读数要写清
  "是那次本机实测"，不能说成"协议总数"。
- 片尾署名、团队名、致谢名单按 §2 与 §4 的结论写。

### 5.1 片子自己的编号（只登记，不需要外部出处）

这张表**只服务一件事**：让 `node tools/lint-fabricated-numbers.mjs <任务>` 零命中。
工具不会判断"这个数重不重要"，它只问"这一串在不在 FACTS.md 里"。
所以镜号 / 卡片序号 / 阶段名里的编号也在这里各占一行 —— 一行话，换掉一次误报。

| 编号 | 出现在哪 | 是什么 |
|---|---|---|
| （例）`WORKS 01`–`WORKS 05` | 各作品镜头的眉标 | 本片的作品镜号，按出场顺序；**不是**作品编号 |
| （例）`L9` / `L0` | 镜头 06 的两张卡片 | 仓库 README 里的校准协议编号，逐字引用 |
| （例）`v0.1.2` | 片尾 | Release tag，出处见 §1 |

> ⚠ **别用 `// numbers-ok:` 注释豁免代替登记**。那个豁免是给"确实不该进事实表的例外"留的
> （工具支持，理由必填且会打进报告），而镜号属于"应该有出处、只是出处是我们自己"的情况：
> 登记一行是证据，豁免只是把问题静音。
