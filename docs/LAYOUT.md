# LAYOUT —— 版面纪律与「版面守门」

> 观众对钠那期视频（`tasks/sodium`）的反馈里有一条：**「有些动画元素相互遮挡害得我搞不清楚到底
> 要看哪个主体」**。这句话在产物上**可复现**（逐帧统计：一屏 4–6 个信息块、最多的段一帧 9 块、
> 单场景文字调用 14 处），而引擎当时**一条判据都没有** —— 亮度统计看不出"元素太多"，
> `check` 只管亮度 / 背景守门 / 非有限值 / 依赖令牌。
>
> 这份文档写两件事：**一条纪律**（每屏只让观众看一件事）与**它的机器判据**（`anim check` 的
> 「版面守门」那一段）。判据的代码在 `src/layout.js`（纯函数）+ `src/app.js` 的 `layoutRows()`
> + `scripts/anim.mjs` 的 `cmdCheck()`；离线单测 `tools/test-layout.mjs`（31 项）。

---

## 1. 纪律（写画面之前先定）

1. **一屏只有一个主体。** 观众看向哪里，是**你**决定的，不是他自己找的。
   这一屏要讲的那件事（图示 / 大数字 / 曲线）是主体，其余一切都得是**标注**。
2. **主体之外最多两块。** 页眉、说明条、脚注**不算**（它们是这一支片子的版式母题，见 §3）。
   超了就是「一屏多头」，观众会不知道该看哪个 —— 这正是钠那期的原话。
3. **读数一次只揭一个。** 同屏一次亮 6 个数，等于 6 个数都没被读进去。
   钠的 `glass` 段一帧 49 次文字绘制、合并之后 9 块 —— 判据会点名它。
4. **画面文字只放标注**（名词 / 数字 / 单位 / 出处），**句子交给旁白与字幕**。
   同屏两套完整句子就是观众说的"两条字幕"（`docs/CAPTIONS.md` 纪律 1、`lint-narration-dup`）。
5. **声明主体**：场景对象上写 `focus`（或时间线段上写），判据才知道"哪里是主体" ——
   不写不是"通过"，是**没判**（`check` 会进 `skipped`，`--strict` 下算失败）。

## 2. 判据：`anim check` 的「版面守门」

```sh
node scripts/anim.mjs check <任务>            # 默认：只 warn，不改退出码
node scripts/anim.mjs check <任务> --strict   # 把这条路也变成门（退出码 1）
node tools/test-layout.mjs                    # 判据本身的离线单测（不需要 GPU）
```

**判据两条半**（都在纯函数 `layoutVerdict()` 里）：

| # | 判据 | 阈值 | 说的是什么 |
|---|---|---|---|
| ① | **一屏几块字** | `maxBlocks = 6` | 同屏的信息块太多（钠的 `glass` 一帧 9 块 / `cull` 8 块） |
| ② | **主体之外有几个「看的地方」** | `maxOffSubject = 2` | 「不知道要看哪个主体」的直接读数（不要求声明 focus） |
| ③ | **主体区里压着几块** | `maxInFocus = 2` | 「元素互相遮挡」—— **只在声明了 `focus` 的段才跑** |

**「块」怎么算**（`textGroups()`）：把挨得近的文字合成一块再数。
判据不是"数调用次数" —— 右上那 6 个读数是 6 次调用、**观众看见的是一块**。
合并阈值**随字号缩放**（`min(gap, 较小字号 × 0.8)`，地板 12px）：
size 18 的读数行距 26px 会合成一块，size 96 的标题与下方 34px 处的读数**不会**被并进去。
（两版固定阈值都在单测里当场翻车过：36 把两行 size 24 的标签并了，28 又把读数并进了大字。）

**采样**：每段 15% / 50% / 85% 三个时刻（`--quick` 只采 50%），与逐段亮度守门**同一批渲染**
（`layoutRows()` 不渲染，读的就是那两帧留下的 `gl.paint.blocks`）。报告取**最挤的那一帧** ——
观众记住的是峰值，不是平均；同时给出"有几个采样点超限"。

**退出码**：与 `docs/BACKLOG.md` 1-19 同一条哲学 —— **默认只 warn，`--strict` 才进 errs**。
理由很实际：这套阈值是一条**新纪律**，现在每个任务都必然超限；让 `check` 默认非零退出，
`tools/regress-all.mjs` 会永久染红，反而没人看了。**交付自检跑 `--strict`**，日常回归跑默认。

## 3. 声明主体：`focus`

三种写法，位置两处（**段上的优先**，同一支片子里某一段想换主体时不必改场景）：

```js
// ① 场景对象上（这一段的默认主体）
export default { id: 'chart', focus: 'center', render(ctx) { … } };

// ② 时间线段上（覆盖场景那一份）
cut(chart, { dur: 6, focus: { x: 480, y: 180, w: 960, h: 760 } }),

// ③ 配置档节点上（B 档同样支持 —— focus 是**时间线字段**，不是模板参数）
{ type: 'chart', values: […], dur: 5, focus: 'center' },
```

| 写法 | 含义 |
|---|---|
| `focus: 'center'` | 画面中心 **46% × 50%**（`CENTER_FOCUS`：左右各留 27%、上下各留 25%） |
| `focus: { x, y, w, h }` | 逻辑像素的矩形（左上角 + 尺寸） |
| `focus: { cx, cy, w, h }` | 给中心点 |
| 不写 | **没判** —— 判据 ③ 不跑，`check` 会在 `skipped` 里点名这一段 |

判据怎么用它（`focusOverlap()`）：一块字与主体区**重叠面积 ≥ 它自己面积的 50%** 才算"在主体区里"。
「主体」的定义是**图连通**的：落在主体区里的块 ∪ **最大的一块**，再把空间上连着的块并成一个
「看的地方」。所以一块读数组里的 6 个数**不会**互相算成"抢视线"（它们是一件事），
而它旁边隔开的那块字才算一次真正的"多了一个东西"。

### 版面母题保留区（`RESERVED_BANDS`）

页眉（y ≤ 11.5%H）与说明条 / 脚注（底边 ≥ 90%H）上的字是**这一支片子的版式**，
**既不算判据、也不算读数**。没有这条豁免的话，钠那种"每段都有页眉 + 说明条 + 脚注"的片子
**每一段都必然超限**，判据立刻变成噪声。三个带与 `src/kit/bands.js` 同源
（页眉 y≈92 / 说明条 y≈964 / 脚注 y≈1018，1920×1080 基准）。

## 4. 阈值可以按任务调

```js
// tasks/<任务>/task.config.mjs（顶层；也可以写进 style: { name: …, layout: {…} }）
export default {
  // …
  layout: { maxBlocks: 8, maxOffSubject: 3, gap: 24, minAlpha: 0.2 },
};
```

| 键 | 默认 | 含义 |
|---|---|---|
| `maxBlocks` | 6 | 一屏最多几块文字（含读数） |
| `maxOffSubject` | 2 | 主体之外最多几个「看的地方」 |
| `maxInFocus` | 2 | 主体区里最多几块 |
| `gap` | 28 | 合并成一块的**上限**（实际阈值 = `min(gap, 较小字号 × 0.8)`，地板 12） |
| `minAlpha` | 0.25 | 低于这个不透明度的绘制不算"占了一屏"（还没揭晓的字） |

`check` 会把当前阈值打出来（`（上限 6；主体之外 ≤ 2）`）—— 阈值是**看得见**的，改没改一眼就知道。
**别为了让 check 变绿去调阈值** —— 阈值是纪律的表达，不是它的反义词。

## 5. 它能看到什么、看不到什么（诚实清单）

**能**：同一帧里有几块字、哪块在主体区里、主体之外还有几个"看的地方"。
数据来源是**实际发生的绘制**（`gl.paint.blocks`，由 `src/core/text.js` 的 `noteText` 记下来），
**只看场景自己那一层** —— 引擎的字幕层 / HUD 层 / 错帧卡片画在别的图层上，天然不算进去。

**不能**：
- **看不出"一块字被别的元素盖住"** —— 它不读像素；那是"元素互相遮挡"的另一半，靠人眼看图；
- **看不出 3D 几何、矢量图形、面板边框**：只数**文字块**。所以"一屏 5 个面板 + 1 行字"它不会响；
- **看不出"这一块字该不该在"**：读数面板本身没错，错的是"一次全亮"。判据只能说"块太多"。

## 6. 钠那一期的实测（判据的标定夹具）

```sh
node scripts/anim.mjs check sodium --strict
```

2026-10-16 实测（三条外部批评逐条对上产物）：

| 批评 | 判据的输出 |
|---|---|
| 「不如纯看字幕了 / 不明所以」 | `[旁白复述] 12 句旁白被逐字写进画面`（43 句里 28%，`lint-narration-dup`） |
| 「元素相互遮挡，不知道要看哪个主体」 | `[版面守门] glass：一屏 9 块文字（上限 6）；主体之外还有 7 个"看的地方"（上限 2）` |
| 「一屏的东西太多」 | `⚠ 版面守门：11/12 段一屏的东西太多`，含 `cull` 8 块 / `threads` 8 块 / `vram` 7 块 |
| 没开字幕层 | `⚠ 这支片子有 43 句旁白，但**没开字幕层**`（`captions: true` 缺失） |

**不返工 sodium**（用户的既有原则：已交付的当教训，不当返工对象）—— 它的价值是夹具。
`focus` 也没给它加：那是"下一支怎么写"，不是"这一支怎么补"。
